## Database Schema

### EmergencyContact (upgraded)
```
ownerId (indexed)
name, relationship (12 types), phone (E.164), countryCode, email
isPrimary (exactly 1 per user, partial unique phone index)
isFavourite, availabilityStatus (AVAILABLE/BUSY/UNAVAILABLE)
channelPreferences[] → { channel, enabled, address }
verificationStatus (UNVERIFIED/PENDING/VERIFIED/FAILED)
notificationLog[] (last 50, capped)
totalAlertsSent, totalAlertsDelivered, totalAlertsFailed
priority (1-20), avatarColor
```

### EmergencyContactInvitation
```
ownerId, ownerDisplayName, ownerCallsign
contactName, contactPhone, emergencyContactId
inviteeUserId (resolved from phone if RidePulse user)
token (hex), tokenExpiresAt (48h TTL index)
status: PENDING | ACCEPTED | REJECTED | EXPIRED | CANCELLED
requestedChannels[], message, rejectionReason
```

### EmergencyContactActivity (19 event types)
```
CONTACT_CREATED, CONTACT_UPDATED, CONTACT_DELETED, CONTACT_RESTORED
PRIMARY_SET, PRIMARY_CLEARED, FAVOURITE_TOGGLED, AVAILABILITY_CHANGED
VERIFICATION_INITIATED, VERIFICATION_COMPLETED, VERIFICATION_FAILED
INVITATION_SENT, INVITATION_ACCEPTED, INVITATION_REJECTED
NOTIFICATION_SENT, NOTIFICATION_DELIVERED, NOTIFICATION_FAILED
PRIORITY_CHANGED, CHANNEL_UPDATED
```

### EmergencyNotification
```
trigger: SOS_TRIGGERED | CRASH_DETECTED | GUARDIAN_STAGE3 | MANUAL_ALERT | RIDE_OVERDUE | INACTIVITY_TIMEOUT
channelAttempts[] → { channel, address, status, messageId, error }
status: QUEUED → DISPATCHING → SENT → DELIVERED | FAILED | RETRYING | EXHAUSTED
retryCount, maxRetries (default 3), nextRetryAt
Cross-refs: sosIncidentId, guardianSessionId, rideId
```

## Priority Engine

```
sortByPriority(contacts) → sorted by:
  1. isPrimary = true  → always first
  2. priority ASC      → lower number notified first (1-20)
  3. isFavourite = true → tie-break
  4. verificationStatus VERIFIED → tie-break
```

## Dispatch Engine (Fallback Logic)

```
For each enabled channel in order: CALL(0) → SMS(1) → WHATSAPP(2) → PUSH(3) → EMAIL(4)
  → attempt notification
  → on success: log, update counters, STOP (don't spam)
  → on failure: try next channel
  → if ALL channels fail: status = FAILED, increment totalAlertsFailed
  → retryCount < maxRetries: schedule retry via nextRetryAt
```

## Sequence Diagram

```
Rider triggers SOS
       ↓
SOSService.triggerSOS()
       ↓
EmergencyContactService.dispatchEmergencyToAll({ trigger: 'SOS_TRIGGERED' })
       ↓
EC.find(ownerId, active, not UNAVAILABLE) → sortByPriority()
       ↓
For each contact → EmergencyNotification.create(status=DISPATCHING)
       ↓
dispatchToContact() → channelPreferences sorted (CALL→SMS→WHATSAPP→PUSH→EMAIL)
       ↓
notificationEngine.sendSms() / sendWhatsApp() / etc.
       ↓
On success → break, log, increment counters
On failure → try next channel
       ↓
notification.save(status=SENT|FAILED)
       ↓
EmergencyContactActivity.create(activityType=NOTIFICATION_SENT)
```
