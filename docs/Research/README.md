# 🔬 RidePulse Research & Technical Spikes

This directory contains technical research notes, zero-cost API evaluations, mesh networking protocols, and offline map rendering benchmarks.

## Evaluated Technologies

- **OpenStreetMap & Leaflet / MapLibre**: Vector map rendering without paid Google Maps Platform API key requirements.
- **OSRM (Open Source Routing Machine)**: Self-hosted / open-source turn-by-turn route calculations.
- **Socket.IO + WebSockets**: Low-latency real-time rider tracking and emergency SOS broadcast.
- **Turf.js**: Client-side & server-side geospatial calculations (haversine distance, speed, bounding boxes).
